# Project Brain (pointer)

The project brain is the structure below. It is the only source of truth; this file only points to it.

- `.ai/`: state and handoff (`project-context.md`, `current-state.md`, `handoff.md`, `state.json`, `repo-snapshot.md`, `active-task.md`, `change-manifest.md`).
- `docs/junior-guide.md`: start here.
- `docs/architecture/`: system map, module map, dependency map, runtime flows, standards audit.
- `docs/features/index.md`: feature map and owner checklists.
- `docs/changes/change-map.md`: where a change belongs; protected boundaries.
- `docs/decisions/`: ADRs 0001 to 0007.
- `docs/reference/`: decision log, lessons learned, map formats.
- `docs/REVIEW_2026-10.md`: architecture review of 2026-10-25 (historical snapshot; the live work list is `docs/architecture/standards-audit.md`).
