# Architecture review and refactor plan (2026-10-25)

> Moved from `docs/REVIEW_2026-10.md` on 2026-10-25. This is a dated snapshot. Its scope line names the legacy files that were removed the same day; their content is in `docs/reference/` and `docs/decisions/`. The live work list is `docs/architecture/standards-audit.md`.

## 1. Summary
The layering idea is sound: Domain, Application (contracts), Infrastructure (I/O), Wpf (composition and UI). The main problems are in three places:
1. **Big view models with many partial files** (`MapViewModel`, `TableQueryViewModel`, `MonitoringViewModel`). They mix state, I/O orchestration, UI messages and layout rules.
2. **Two-way bindings on derived state** (the crash loop, N1) and **nulls from controls** (N2).
3. **No ViewModel tests.** Every serious bug of this phase was visible only in the running UI.

Second-order problems: presentation data in Domain, a serializer attribute in Domain, one class implementing two writer contracts, and a few places where UI code calls into Infrastructure types directly.

## 3. What is good and should stay
- Read-only guard, typed parameters, server-side paging.
- `CoordinateRules` and `MapLayer` invariants in the constructor.
- Atomic JSON writes (temp file and move) in the layer and monitor stores.
- `CsvPartsWriter` cleanup on failure and cancel.
- Credential flow: vault first, profile flag second; no password in profile JSON.
- Single persistent map view with explicit release (after the N3 fix).

## 4. Refactor plan (phased, each phase needs owner approval)
- **R1** Safety net: ViewModel tests (blocked by the target framework, D38).
- **R2** Move presentation data out of Domain (F6, F7, F8).
- **R3** Split the big view models (F1, F2): filter builder, paging controller, map send coordinator, map document, layers, results, tools.
- **R4** One binding policy: TwoWay only for user input; derived state as OneWay plus command.
- **R5** Composition: one registration per interface; `AppPaths` (F9, F10).
- **R6** Map JavaScript modules: split `layers`, `selection`, `tools-geo`, `tools-ui`; pure functions tested with Node.
- **R7** Dependencies: central package management, pinned versions, Pkcs advisory.

Current status of each item: `docs/architecture/standards-audit.md`.
